# Board Game Store

**University:** University of Belgrade, School of Electrical Engineering  
**Course:** Web Design  
**Year:** 2025/2026  
**Team project** (2 members)

## Overview

A responsive web presentation for a board game store, developed with Vue as part of the Web Design course.

The website allows visitors to browse and search through a catalog of board games, view detailed game information, leave ratings and comments and manage their shopping cart and orders. The website supports both Serbian and English.

## Features

- Responsive web design
- Serbian and English language support
- Board game catalog
- Family, Strategy and Party game categories
- Game search and sorting by name and price
- Detailed game information
- Ratings and comments
- Persistent ratings and comments using `localStorage`
- Shopping cart and quantity management
- Checkout and order history
- `localStorage` based data persistence
- PDF catalog generation
- Image and video galleries
- Promotions, discounts and events
- Store information and contact details
- Interactive store map

## Pages

- Home

- My Account
- About Us

## Installation and Setup

### Requirements

- Node.js 22.21.0
- npm

### Create Vue Application

Create a new Vue application using:

```bash
npm create vue@latest
```

During setup, select the following options:

- **Project name:** choose a project name
- **TypeScript:** No
- **Add Vue Router:** Yes
- **Add ESLint for code quality:** Yes
- **Add experimental features:** No
- **Select a variant:** JavaScript

After creating the project, replace the generated source files with the project files from this repository.

### Run the Application

Navigate to the project directory:

```bash
cd <project-folder>
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available in the browser at:

```text
http://localhost:5173/
```
